# jdwm

This is the Dart & Flutter implementation of the JDWM window manager used by the JappeOS desktop environment.

JDWM boolean environment flags are disabled when unset, empty, or equal to
`0`, `false`, `off`, or `no` (case-insensitive). Other nonempty values enable them.
